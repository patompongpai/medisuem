คัดกรอง — ใครต้องถ่าย CXR

  • ประชากรทั่วไป ที่มีอาการสงสัย (ไอ ≥2 สัปดาห์ ไอเป็นเลือด น้ำหนักลด ไข้ เหงื่อออกกลางคืน) → CXR
  • Key populations (HIV, DM คุมไม่ได้, กดภูมิ, COPD/สูบบุหรี่, silicosis, CKD, ผู้สัมผัส, ผู้สูงอายุมีโรคร่วม, ผู้ต้องขัง, บุคลากร ฯลฯ): รายใหม่ CXR ทุกราย; รายเก่าคัดกรองอาการทุก visit → มีอาการจึง CXR; ปกติ CXR ปีละครั้ง

เก็บเสมหะ & ส่งตรวจ

เสมหะอย่างน้อย 2 ครั้ง (spot + เช้าตื่นนอนก่อนแปรงฟัน) ปริมาตร 3–5 mL ห้ามเก็บในห้องน้ำ CXR เข้าได้กับ TB → AFB smear → ลบ: Xpert MTB/RIF (หรือ TB-LAMP) · บวก: FL molecular (LPA / RT-PCR / Xpert Ultra) เพื่อดู RIF/INH

สถานการณ์ที่เข้าถึง CXR ยาก: คัดกรองอาการแล้วส่ง molecular ได้เลย น.53 · ผู้ติดเชื้อ HIV ส่ง Xpert ได้เลย + smear/culture (แยก NTM)

แปลผล จำแนกและขึ้นทะเบียน NTIP

จำแนก B+ / B−, P / EP, HIV status และประเภทขึ้นทะเบียน (N, R, TAF, TALF, TI, O) — ทุกรายที่วินิจฉัย TB ต้องขึ้นทะเบียน รวมถึงผู้ที่เสียชีวิตก่อนหรือไม่ได้เริ่มยา

Baseline ก่อนเริ่มยา

  • ชั่งน้ำหนัก (คำนวณยาจากน้ำหนักก่อนเริ่มรักษา), อาการทางคลินิก, CXR, AFB smear, molecular/DST
  • HIV test ทุกราย (ภายใน 1–2 สัปดาห์แรก, PITC)
  • LFT ในกลุ่มเสี่ยงตับอักเสบ: อายุ >60, ดื่มสุรา, โรคตับ/HBV/HCV, HIV, ทุพโภชนาการ, ตั้งครรภ์
  • BUN/Cr ในกลุ่มเสี่ยงไต · ตรวจการมองเห็นในผู้สูงอายุหรือมีโรคตาเดิม

ติดตามระหว่างรักษา

นัดทุกเดือน: อาการ + น้ำหนัก · smear สิ้นเดือน 2, (3 ถ้าเดือน 2 บวก), 5, 6 · CXR เดือน 2 และ 6 · ถามการมองเห็นทุกครั้ง · LFT ทุก 1–2 สัปดาห์ในเดือนแรกถ้ามีความเสี่ยง

ปัญหาระหว่างรักษา

  • ขาดยา/หยุดยา → ประเมินตามแผนภูมิ 5.1 (ขาดยา ≥2 เดือนติดต่อกัน = lost to follow-up → ขึ้นทะเบียนใหม่ TALF)
  • เสมหะยังบวกสิ้นเดือน 2 → ส่ง molecular + culture/DST; บวกเดือน 5 = failure
  • พบ RR/MDR → ส่ง SL-LPA/RT-PCR ด่วน → shorter vs individualized longer regimen
